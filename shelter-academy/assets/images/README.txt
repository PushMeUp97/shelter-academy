This folder is where your images live — logo, favicon, and any photos used
across the site.

Suggested files to add (referenced once you drop them in and wire up the
<img> tags / CSS):

  logo.svg          — used in the header brand mark instead of the "SA" text badge
  favicon.ico        — browser tab icon, linked from <head> in each page
  og-image.jpg        — social share preview image, 1200x630px recommended

No images are required for the site to work — it currently renders entirely
in CSS/HTML (no broken-image placeholders to clean up later).
