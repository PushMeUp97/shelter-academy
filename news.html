Key recommendations

1. Update navigation

Add a persistent "News" link to the primary navigation (done) so visitors can quickly find announcements.

2. Centralize styling

Move shared styles into css/style.css so the News page matches the rest of the site and is easy to maintain.

3. Use consistent structure for posts

Each news post should include a date, title, and content block. That makes it easy to add, parse, or migrate posts later.

4. Keep content in HTML for now

Since the site is primarily HTML, adding posts directly to this file is simple. If you later want dynamic posting, consider integrating a simple backend or a headless CMS.

5. Accessibility & metadata

Include semantic tags (e.g., <article>), appropriate headings, and descriptive link text. Add meta descriptions if posts will be shared externally.
